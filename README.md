# Soehnle AC500 integration for Home Assistant

## Installation

### From HACS

1. Install HACS if you haven't already (see [installation guide](https://hacs.xyz/docs/use/download/download/)).
2. Add custom repository `https://github.com/Meaxl/soehnle-ac500` as "Integration" in the settings tab of HACS.
3. Find and install "Soehnle AC500" intergration in HACS's "Integrations" tab.
4. Restart your Home Assistant.
5. Add "Soehnle AC500" integration in Home Assistant's "Configuration -> Integrations" tab.

### Manual

1. Download and unzip the [repo archive](https://github.com/Meaxl/soehnle-ac500/archive/master.zip). (You could also click "Download ZIP" after pressing the green button in the repo, alternatively, you could clone the repo from SSH add-on).
2. Copy contents of the archive/repo (`custom_components/soehnle_ac500/.`) into your `/config` directory.
3. Restart your Home Assistant.
4. Add "Soehnle AC500" integration in Home Assistant's "Configuration -> Integrations" tab.
